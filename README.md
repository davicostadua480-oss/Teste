# Nebula Tribunal

Protótipo experimental de site futurista/interativo criado para testar um repositório GitHub.

## O que tem aqui

- Landing page cinematográfica
- Dashboard interativo
- Simulador com controles
- Catálogo filtrável
- Cards de preço
- FAQ em acordeão
- Modal de demo
- Paleta de comandos com `Ctrl + K`
- Modo claro/escuro salvo no navegador
- Animação de estrelas em canvas
- Responsivo para celular

## Como abrir

Basta abrir `index.html` no navegador.

## Como publicar no GitHub Pages

1. Envie estes arquivos para o repositório.
2. No GitHub, vá em `Settings`.
3. Entre em `Pages`.
4. Em `Branch`, selecione `main`.
5. Escolha `/root`.
6. Salve.

Depois o GitHub vai gerar um link público para o site.

## Estrutura

```text
index.html
styles.css
script.js
README.md
```

## Observação

Este projeto não usa backend nem banco de dados. É uma demo visual em HTML, CSS e JavaScript puro.
